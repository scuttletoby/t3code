# Fork changes

This repository is a fork of [T3 Code](https://github.com/pingdotgg/t3code). This page lists every
change the fork makes, one line each: what it does, why, its setting and default, and the pull
requests. The fork's settings are explained in [docs/fork/README.md](docs/fork/README.md), which also
says how to install the fork today.

The rule for every change: a machine that never names a fork setting behaves as upstream's T3 Code.
A setting is written as `server.<key>` (the server's `settings.json`) or `projectOverride.<key>`
(one project's overrides). A test (`packages/shared/src/forkDocs.test.ts`) fails when a fork setting
is missing here or a setting named here does not exist.

## Adding a line

A pull request that adds or changes a fork feature adds or changes its line here. A new fork setting
also needs its row in `packages/contracts/src/forkDefaults.ts` and its row and section in
[docs/fork/README.md](docs/fork/README.md) (steps in [updates.md](docs/fork/updates.md#adding-a-fork-setting)).
