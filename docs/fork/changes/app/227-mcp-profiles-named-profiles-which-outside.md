- Change: MCP profiles: named profiles (which outside MCP servers and T3 tool groups a thread gets), a default, a sub-agent rule, a pick per thread and the rules that pick one. Claude and Codex apply the outside servers (Codex per thread, as `mcp_servers.<name>.enabled = false`) and refuse a turn when they cannot; any other provider refuses a turn whose profile leaves one out. T3's MCP server applies the T3 tool groups on every provider, fixed as each turn starts: a tool outside them is hidden and refused. A delegated task carries its parent's profile; a narrower one goes only to a Claude instance on a machine that applies it. Settings → Fork edits profiles, the default, the sub-agent rule (also per project) and each thread's pick.
- Why: Fewer tools per thread saves tokens and keeps agents from tools they should not use.
- Setting: `server.mcpProfiles`, `server.mcpProfile`, `server.mcpSubagentProfile`, `server.mcpThreadProfiles`, `server.mcpCarriedProfiles`, `projectOverride.mcpProfile`, `projectOverride.mcpSubagentProfile`
- Default: off
